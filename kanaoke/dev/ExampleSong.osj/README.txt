This is a sample song map for testing Kanaoke.

To use this sample:
1. Place an audio file (mp3, wav, or ogg) named "audio.mp3" (or audio.wav/audio.ogg) in this folder
2. The timing.json is already set up with example timestamps
3. You can import this folder using the Import feature in Kanaoke

Note: The timing values are examples. You'll need to adjust them to match your actual audio file using the Sync Editor.
